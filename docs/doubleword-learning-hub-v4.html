Batch Mode — Maximum Savings

JSONL file → upload → process → retrieve. 24h SLA for deepest discounts.

client = OpenAI(api_key="dw-...", base_url="https://api.doubleword.ai/v1")

# 1. Upload JSONL
f = client.files.create(file=open("batch.jsonl","rb"), purpose="batch")

# 2. Create batch
batch = client.batches.create(
    input_file_id=f.id, endpoint="/v1/chat/completions",
    completion_window="24h"  # or "1h" for faster
)

# 3. Download partial results WHILE still processing
import requests
resp = requests.get(
    f"https://api.doubleword.ai/v1/files/{batch.output_file_id}/content",
    headers={"Authorization": "Bearer dw-..."}
)
# Check resp.headers["X-Incomplete"] for partial status
DW advantage: Download partial results while processing (OpenAI makes you wait). Max 200MB / 50K requests per file. Webhooks available.

Self-Hosted LLM Infrastructure

Deploy open-source models on your own GPUs with production-grade tooling.

Core Components

1
Helm Charts
Kubernetes-native deployment. Model groups, scaling, volumes.
2
Bit Harbor
Pre-built containers with popular model weights. No download delays.
3
Pre-Porter
Scheduled job distributes model containers across all nodes before needed.
4
Multi-Engine
vLLM, TensorRT-LLM, SGLang, Dynamo — pick the right engine per workload.
📝 Behind the Stack Ep 8: Choosing Engines
Local (Llama.cpp, mistral.rs): Portable, lightweight, personal use.
Server (vLLM, TRT-LLM): Multi-tenant, high-throughput, GPU-optimized.
Distributed (Dynamo): Disaggregated prefill/decode, cloud-scale.
Choose based on: who's using it, where it runs, and call frequency.
📝 Ep 4: LLM-Aware Load Balancing
Traditional round-robin fails for LLMs — a 50-token vs 10K-token request have wildly different GPU cost. Route by KV cache utilization, not CPU metrics.

Model Loading: Bit Harbor + Pre-Porter

LLM weights take minutes to download at startup. InitContainers eliminate this.

# Helm chart values
modelGroups:
  vllm-example:
    initContainers:
      - name: copy-model-weights
        image: ghcr.io/doublewordai/bit-harbor:gemma-3-12b-it
        command: ["/pause"]
        volumeMounts:
          - name: models
            mountPath: /models
    volumeMounts:
      - name: models
        mountPath: /root/.cache/huggingface
        readOnly: false
    volumes:
      - name: models
        emptyDir:
          sizeLimit: 50Gi
Pre-Porter runs as a cron job pulling model containers to all worker nodes hourly. Target GPU nodes only with nvidia.com/gpu.present: "true" node selectors.

Engineering Deep Dives

Key Insights from the Blog Series

Ep 9 · Evaluating LLMs
Benchmarks (MMLU, ARC) don't always reflect real-world use. LM Arena uses blind head-to-head with ELO scoring — closest to how real users experience models. Build in-house evals for your exact task, but use Arena as first stop.
Gateway Benchmarking
dwctl (Rust) adds imperceptible overhead at 100 concurrent users. LiteLLM adds >1s to median requests. Self-host your gateway — don't let a cloud proxy man-in-the-middle your AI requests.
Parallel Primitives
Multi-agent workflows need parallel batched calls. Autobatcher handles this transparently: asyncio.gather + BatchOpenAI. Mix chat completions, embeddings, and responses in a single batch.
